## 一、设计目的与哲学

**日程规划**（此名称刻意保持中性以保护用户隐私）是一个**18岁以上成年人自愿使用**的私密训练日程管理工具。它既不是"禁欲打卡器"，也不是简单的"色情任务列表"——它是一套**完整的、性别感知的自律训练与欲望管理框架**。

### 核心设计理念

1. **自主选择，自我管理**
   没有任何外部控制或强制。所有规则由用户自己设定，工具只是忠实地记录、提醒和统计。用户面对的真正对手是自己设定的规则和自己的身体反应。这种「与自己博弈」的体验，是所有高潮训练最深刻的魅力。

2. **性别双轨制**
   男性与女性在高潮生理上存在根本差异：男性有不应期（refractory period），女性多数无不应期可连续多次；男性的核心训练是射精控制，女性的核心训练是高潮识别和多重体验。本工具针对两种生理体系建立了完全独立的**任务库（男女各38+项）**、**指南内容**和**术语体系**（射精↔高潮、释放日↔高潮日）。

3. **周期与积分的双重哲学**
   - **周期模式**：适合偏好结构化、固定节奏的用户。系统以7天为单位自动编排Denial/Tease/高潮日/休息日的分布，像一份私教课表。强调的是**纪律、节律和可预期感**。
   - **积分模式**：适合偏好自由度和策略性的用户。每天自由选择任务打卡赚分，攒够积分再购买释放。强调的是**延迟满足的张力、资源管理的策略性**（要攒够多少分才购买？每次释放都在抬高下一次的成本）。

4. **100%本地、零联网、隐私至上**
   纯前端单页应用。数据存储在浏览器localStorage中，没有任何后端服务器，没有任何第三方统计，没有任何网络请求。不使用该工具时，它就是本地硬盘上一个普通的HTML文件。标题使用中性词汇"日程规划"，浏览器标签页不会暴露任何敏感信息。

5. **游戏化但保持严肃**
   打卡、积分、释放购买、倒计时、统计图表——这些都是游戏化的激励机制。这不是色情游戏，这是成年人对自身欲望的正视与管理。

## 二、快速开始

### 第一步：选择身份和模式

打开 `index-v5.html`，在欢迎页选择：

- **性别**：男 / 女（决定了整个任务体系、指南内容和术语风格）
- **模式**：周期模式 / 积分模式
- 点击 **开始**

### 第二步：配置训练参数

切换到 **「设置」** 标签页：

**周期模式** — 建议参数：

| 设置项           | 建议值 | 说明                          |
| ---------------- | ------ | ----------------------------- |
| 起止日期         | 100天  | 整个训练周期时长（默认100天） |
| 每日最多任务数   | 4-6条  | 每天生成多少训练项            |
| 启用休息日       | 开启   | 周期中穿插休息日              |
| 强制周末释放     | 开启   | 释放日优先安排在周六/日       |
| 释放模式         | 规律   | 固定节奏 vs 随机分布          |
| 周期最大释放日数 | 4      | 整个周期内最多几个释放日      |

**积分模式** — 建议参数：

| 设置项       | 建议值 | 说明                                       |
| ------------ | ------ | ------------------------------------------ |
| 每日积分上限 | 7      | 每天最多赚多少分（女性猛攻排卵窗口自动×3） |
| 释放费用模式 | 累加   | 每次释放后费用递增                         |
| 基础费用     | 5      | 首次释放需要的积分                         |
| 递增幅度     | 2      | 每次释放后费用+2                           |

### 第三步：选择训练任务

在 **「可选任务」** 区域，勾选你愿意做的训练项。**只勾选自己熟悉并且身体适应的任务**。不勾选的项目不会出现在日程中。

新手建议只勾选：**Kegel练习、无触碰Tease、寸止**，再加一个释放类任务。逐步增加。

### 第四步：生成日程

点击 **「一键生成日程」**，系统自动为整个周期分配每日任务。切到日历查看全部日程。

## 三、周期模式详解

### 3.1 四种基础日型

系统以7天为一个循环单元，自动分配以下四种日型的节奏：

```
Denial → Tease → Denial → 休息 → Tease → Denial → 高潮日 → (循环)
```

| 日型                 | 日历颜色 | 含义                              | 男性典型任务                                | 女性典型任务                                          |
| -------------------- | -------- | --------------------------------- | ------------------------------------------- | ----------------------------------------------------- |
| **Denial（禁欲日）** | 红色     | 强调控制与克制，禁止任何释放行为  | 禁止触摸、佩戴贞操锁、寸止(3次)、Kegel      | 禁止触摸、仅限视觉挑逗、寸止(3次)、Kegel、凯格尔球    |
| **Tease（挑逗日）**  | 紫色     | 允许各种刺激但保留在临界值以内    | 无触碰Tease、震动棒、节拍器挑战、红绿灯游戏 | 阴蒂刺激、震动棒、G点探索、乳头刺激、花洒冲击、节拍器 |
| **高潮日/释放日**    | 绿色     | 允许完整释放。一般安排在周末      | 完整射精、毁灭高潮、多次射精、笼内高潮      | 完整高潮、毁灭高潮、多次高潮训练、强制高潮、潮吹探索  |
| **休息日**           | 灰色     | 低强度恢复，仅保留Kegel等轻度训练 | Kegel、轻松Tease、禁止触摸                  | Kegel、放松冥想、情色阅读、身体按摩、No-Touch         |

### 3.2 日程生成逻辑

1. **开始日期和结束日期**由用户设定（默认100天）。
2. 系统首先按「**周期内最大释放日数**」分配**释放日**：数量完全由此参数控制，按最小释放间隔和释放模式（规律/随机）分布在周期中。规律模式下释放日优先排在周末。末日确保至少1个名额。
3. **休息日**按3-7天间隔插入。
4. 剩余天数交替分配 **Tease** 和 **Denial**。
5. 每天从对应的**任务池**中按优先级随机抽取，直到达到用户设定的每日任务上限。核心任务（如Kegel）必出，非核心任务约70%概率出现以增加变化。
6. **释放日禁止寸止**：释放日本身含射精/高潮任务，系统自动从该日任务池移除寸止，避免消耗精力影响释放体验。

### 3.3 日历操作

- **切换视图**：月/周/日三种粒度
- **点击日期**：打开日详情弹窗，可勾选任务打卡、添加备注、现场追加惩罚任务
- **添加惩罚任务**：每日可手动额外为当天添加惩罚项（如额外寸止、高潮后刺激等），惩罚任务不参与自动生成
- **重新生成**：在日历底部可针对今日/本周/本月/全部重新生成，已打卡记录保留

### 3.4 高潮日倒计时

header 区域固定显示距下一个高潮日的倒计时：

- `⏳ 距下一个高潮日还有 X 天`（正常倒计时）
- `🎯 明天是高潮日`（临近提醒）
- `🎯 今天就是高潮日！`（当天高亮）

统计面板中也有对应的倒计时卡片。这个设计利用了**"期待效应"**：知道终点在哪里的训练比无尽头的禁欲更容易坚持，心理学上称为"目标梯度效应"（goal-gradient effect）。

### 3.5 任务列表

按日期分组展示所有日程，支持**今天 / 全部 / 未完成**三种筛选。每项任务可点击打卡，完成进度实时更新。底部备注框可自由记录当日感受。

## 四、积分模式详解

### 4.1 核心循环

```
选择每日任务 → 打卡确认 → 获得积分 → 积累到足够分值 → 购买释放日 → 选择释放方式并执行 → 费用递增 → 新一轮积累
```

积分模式更适合**"自主性强、喜欢策略性思考"**的用户。它不像周期模式有固定的日型节奏，而是把控制权交给了积分这个"货币"。

### 4.2 每日打卡

点击日历底部的 **「📋 今日打卡」** 按钮：

1. 在弹窗中勾选今日完成的任务（阴蒂刺激、Kegel、震动棒……）
2. 每项任务有对应的积分值（基础1分，猛攻模式排卵窗口内×倍率）
3. 当日积分不超过用户设置的**每日积分上限**（女性猛攻排卵窗口内上限自动×3）
4. 高潮/释放类任务（射精、毁灭高潮等）不在日常打卡中出现，仅在释放日可用
5. 寸止任务允许多次打卡（每次生成独立ID）

### 4.3 释放购买

页面底部固定显示**🔓 花费积分释放**按钮：

1. **购买**：点击按钮 → 确认消耗X积分 → 获得当日释放资格
2. **使用**：再次点击 → 弹窗选择释放方式（完整射精/高潮、毁灭、多次等）→ 执行释放
3. **过期**：释放资格仅当天有效，跨夜自动作废（积分不退还）

### 4.4 积分经济系统

| 机制             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **累加费用**     | 基础 + 递增 × 释放次数。例如基础5分、递增2分，则第1次5分、第2次7分、第3次9分……可设上限 |
| **固定费用**     | 每次释放都是同一分数，简单直接                               |
| **随机费用**     | 每次释放费用在用户设定的上下限范围内随机取值，增加不可预测性 |
| **强制周末释放** | 开启后只能在周六/日购买释放                                  |
| **难度积分**     | 寸止和贞操锁/贞操带支持3个难度等级，各获得3/4/5分            |
| **作弊模式**     | 统计页连续按↓5次激活，+999分，连续按↑5次取消并恢复原始数据（仅限测试用，积分要自己赚才有意义） |

### 4.5 积分模式下的心理博弈

**"存还是花"是积分模式最核心的张力**：

- **攒着不花**：积分存起来为下一次释放做准备。但代价是继续等待，延迟满足。
- **现在花**：即时获得释放资格，但释放后费用递增，下一次更贵。

这模拟了真实生活中的储蓄 vs 消费决策。有固定费用的用户倾向于"攒够了就花"；有累加费用的用户更谨慎，因为每次释放都在抬高未来成本。这种经济性约束本质上是一种**"自我施加的稀缺性"**——你自己让自己手中的资源变宝贵。

## 五、女性专属功能

### 5.1 经期与特殊日期

设置页可标记特殊日期：

| 类型         | 行为                                           | 日历标记   |
| ------------ | ---------------------------------------------- | ---------- |
| **请假**     | 当日完全跳过所有任务                           | 黄色 badge |
| **降低强度** | 仅保留Kegel + 放松类任务                       | 蓝色 badge |
| **经期**     | 自动降低为轻度，仅保留 Kegel + 放松冥想 + 日记 | 粉色 badge |

经期日期会在日历上以粉色标记显示。月经期间子宫内膜脱落、子宫收缩，身体处在低能量状态，此时进行高强度训练不仅体验不好，还存在卫生和感染风险。适当降低训练强度、保留盆底肌锻炼和放松活动，是更可持续的策略。

### 5.2 猛攻模式（女性专属）

**核心理念**：女性在排卵期前后雌激素和睾酮水平升高，性欲和敏感度达到周期顶峰。猛攻模式利用这一生理窗口，在此时期强化控制力训练（或者加倍积分激励）。

**三个核心规则**：

1. **周期模式下**：排卵窗口期内自动取消所有高潮日，转为 Denial 或 Tease，同时**每日任务数自动提升至原来的1.5倍（向上取整）**——例如平时每日5个任务，窗口内变成8个。就是要在你最想要的时候说不，并且加倍训练量——这是控制力的终极考验。
2. **积分模式下**：排卵窗口内打卡积分 × 倍率（默认×2），**每日积分上限自动提升至平时的3倍**（如平时7分→窗口期21分）；与此同时**严格禁止在此窗口内购买和执行释放**。积分加倍是奖励，上限放开是便利，但释放被禁是强制约束。
3. **每日询问**：开启猛攻后，每天首次打开页面弹出经期状态询问，记录经期起始日，用于自动推算排卵日。

**排卵日判定**：

| 来源                                                 | 优先级             | 日历标记           |
| ---------------------------------------------------- | ------------------ | ------------------ |
| 手动标记                                             | 最高，覆盖自动推测 | `卵` 实心 badge    |
| 经期起始日自动推算（经期起始日 + 平均周期天数 - 14） | 次之               | `~卵` 半透明 badge |
| 无数据                                               | 不介入             | 无                 |

> 推算结果若已过期，自动按周期天数前滚至未来最近日期，并持续推算至周期结束日为止。日历上会显示**周期范围内所有未来的排卵日**，而非仅最近一个。手动标记同样支持前滚和多日显示。

**日历可视化**：

- 排卵窗口内有浅色边框提示
- 排卵日当天有 badge 标记
- 被拦截的高潮日显示 `🔁 已转换`，弹窗标题中注明原由

**手动标记排卵日**：用户可在设置页面的猛攻设置卡片中选择日期并手动标记。这对于周期不规律或希望更精确控制的用户非常重要。手动标记优先于自动推测。

### 5.3 猛攻日（男性专属）

男性没有生理周期，猛攻日是一个**人为指定的高强度训练窗口**。

选择一个距今至少10天后的日期。猛攻日前后各1天（共3天）为猛攻窗口期。这段倒计时本身就是训练的一部分——你知道风暴在哪几天来临，你走向它。

**周期模式**：窗口期内一切高潮日自动转为 Denial 或 Tease（与女性一致），同时每日任务数×1.5（向上取整）。平时5个→窗口内8个。

**积分模式**：窗口期内积分倍率×设定值（默认×2）、每日积分上限×3（7→21），同时**禁止购买释放、禁止执行高潮**。

**日历标记**：窗口内日期显示 `⚡ 猛` badge + 浅色边框；被转换日显示 `🔁 已转换`。

**设置**：设置页"猛攻日"卡片（仅男性可见），选日期（≥10天后），点击"开始"锁定。

## 六、统计与数据管理

### 6.1 周期模式统计

| 指标             | 说明                             |
| ---------------- | -------------------------------- |
| 连续 Denial 天数 | 距上次释放已过多少天（核心指标） |
| 整体完成率       | 所有任务中已打卡的百分比         |
| 剩余天数         | 距周期结束还有几天               |
| 已完成天数       | 当日所有任务全部完成的天数       |
| 高潮日倒计时     | 距下一个高潮日的天数             |
| 热力图           | 按日/周/月的完成密度可视化       |

### 6.2 积分模式统计

| 指标         | 说明                                               |
| ------------ | -------------------------------------------------- |
| 当前积分     | 可用余额                                           |
| 下次释放所需 | 当前费用模式下需要多少分                           |
| 累计释放次数 | 总共释放了多少次                                   |
| 释放购买状态 | 已购买待使用 / 未购买                              |
| 猛攻额外积分 | 排卵窗口内通过倍率获得的额外积分（仅女性猛攻模式） |

### 6.3 高潮间隔天数分布

积分模式下可以看到最近释放的时间间隔分布，含：

- 最短/最长/平均间隔天数
- 间隔分段柱状图（1-3天 / 4-7天 / 8-14天 / 15-30天 / 30+天）
- 最近10次释放明细表

这一统计帮助用户了解自己的释放频率模式，从数据角度审视训练成果。

### 6.4 数据管理

### 7.1 延迟满足与多巴胺系统

## 九、高潮控制为什么吸引人

### 9.1 "刻意稀缺"制造价值

这是所有高潮控制形式最底层的吸引力来源。当一样东西可以随时随地轻松获得时，它的心理价值趋近于零。但当它被规则限制、被倒计时框定、被积分量化——它会重新变得珍贵。

这个过程不是外界施加的稀缺（你当然可以随时退出训练直接释放），而是**自我选择的稀缺**。正是这种自主性使限制变得有趣而非压抑。

执行Denial日的训练时，一个人同时处于两种角色中：

**控制者**：「我今天不释放，这是我自己定的规矩。」
**服从者**：「我的身体在说想要，但我得服从我的训练计划。」

## 十一、技术架构（简述）

### 11.1 技术选型

- **纯前端单页应用**：HTML + CSS + JavaScript，无任何框架依赖
- **存储**：浏览器 localStorage（三个 key 和快照前缀）
- **渲染**：Vanilla JS 操作 DOM，无虚拟 DOM
- **无外部依赖**：零 npm 包、零 CDN、零第三方脚本

### 11.2 数据模型

```
settings   = { 用户配置：日期、模式、任务选择、猛攻参数…… }
schedule   = [ { date, label, tasks[] } ]  // 日程数组
progress   = { date → { completedTasks[], notes, punishments[] } }
```

## 十二、常见问题

**Q: 数据安全吗？会泄露吗？**

不会。所有数据仅存储在浏览器本地 localStorage 中。这个工具不连接任何服务器，不做任何网络请求。**清除浏览器数据会删除所有记录**，请定期使用"导出数据"功能手动备份。

**Q: 经期数据上传到哪里？**

不到任何地方。经期数据与其他所有数据一样，仅存储在你的浏览器本地存储中。

**Q: 排卵日推算准确吗？**

仅是基于平均周期天数减14天的简化推测，**不是医学诊断**。个体差异很大，实际排卵日可能有3-5天的偏差。建议配合手动标记使用。

**Q: 如果身体不适怎么办？**

使用特殊日期的"请假"功能标记该日，系统会自动跳过所有训练。如果持续不适，请咨询医生。

**Q: 男性可以使用猛攻模式吗？**

不可以。猛攻模式基于女性的生理周期设计，仅在女性模式下可用。

**Q: 为什么有些任务在任务池中看不到？**

需要在设置页的"可选任务"区域勾选你想要的任务类型。只有被勾选的任务才会被纳入生成池。

**Q: 可以换模式吗？**

如果你想切换模式（如从周期模式切换为积分模式），需要重置数据并回到欢迎页重新选择。
